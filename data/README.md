# Data Notes

This portfolio project uses an Inside Airbnb NYC listings dataset containing **36,445 listing records**.

The original working dataset includes listing location, borough, room type, host characteristics, review metrics, superhost status, and estimated booking activity.

The full raw CSV is not duplicated in this repository because the portfolio artifact is focused on the Power BI analysis rather than data redistribution.

Key caveat: the data do not include revenue, profit, true occupancy, acquisition cost, or operating expense. Dashboard conclusions therefore rely on market-size, quality, and activity proxies.
